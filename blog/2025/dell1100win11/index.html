How to install Dell 1100 Print Drivers on Windows 11

Created on May 29, 2025

2025

The Dell Laser Printer 1100 was first released to the public in 2003. Let’s make it work on Windows 11!

Install Dell Laser Printer 1100 Printer on Windows 11

  1. Plug in printer over USB.
  2. Open Settings > Bluetooth & devices > Printers & scanners.
  3. Click the “Add device” button, wait a few seconds, click “Add a new device manually”.
  4. Click the ratio button titled “Add a local printer or network printer with manual settings”, then press the “Next” button.
  5. With the “Use an existing port:” ratio button selected, specify the list item containing “DellLaser Printer 1100”, then press the “Next” button.
  6. Click “Windows Update” and wait several minutes until you see two lists—”Manufacturer” and “Printers”.
  7. Select Dell as the manufacturer and “Dell Laser Printer 1100” as the printer. Be careful as to select the 1100 and not the 1110 model. Then, press the “Next” button.
  8. Name the printer if desired. Then, press the “Next” button.
  9. If you see a dialog box appear saying “The printer driver is not compatible with a policy enabled on your computer that blocks NT 4.0 drivers.” or “Windows can’t install the (model) kernel-mode print driver. To obtain a driver that is compatible with the version of Windows you are running, contact the manufacturer.”, proceed to below.

Fixing kernel-mode driver errors

Follow the steps outlined here by internet user D0rkye or refer to the following summary:

  1. Open Command Prompt as Administrator and type the following commands:
net stop spooler
rmdir /S /Q c:\Windows\System32\spool\drivers\W32X86
rmdir /S /Q c:\Windows\System32\spool\drivers\x64
net start spooler
  1. Open Local Group Policy Editor.

  2. Navigate to Computer Configuration > Administrative Templates > Printers . Set the following by double clicking and pressing “Apply” then “OK” afterwards:

    • Disable “Disallow installation of printers using kernel-mode drivers”
    • Enable “Point and Print Restrictions” and in the same window, under Options, set “When installing drivers from a new connection:” to Do not show warning or elevation prompt and “When updating drivers for an existing connection:” to Do not show warning or elevation prompt
  1. Restart the computer.
  2. Follow steps 1-9 again.
